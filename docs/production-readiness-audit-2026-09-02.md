# Production-readiness audit — 2026-09-02

> **Superseded for status by [codex-production-check-2026-09-02.md](codex-production-check-2026-09-02.md)** — the synthesized final of both audits with every finding's resolution (2026-09-03). This file keeps the original evidence and ranking.

Thirteen layers ("full-stack production reality"), translated to what each means for
StrixGeo: a single-seat desktop app (Electron + React) over a LOCAL FastAPI backend and a
bundled PostgreSQL, shipped as an unsigned NSIS installer with a natively compiled engine.
Method: four parallel read-only audits (frontend/API/logs · database/caching/recovery ·
auth/security/rate limiting · deployment/cloud/CI/scaling) on develop `2659b9724`, each with
`file:line` evidence, then one ranking pass. Nothing was executed against a database or a
running app; the fixes are the smallest that close each item. Debt numbers refer to
`docs/debt.md`.

## Top 10 before the closed beta (ordered; all S unless noted)

1. **C2** — token required whenever an Origin header is present; localhost CORS only in development; one regression test.
2. **C1** — `package`/`dist` refuse without the beta stamp; post-build grep gate. Rebuild the installer with the stamp set.
3. **C3 a-c** — no mock issuer in packaged builds; e2e flag gated on `!isPackaged`; device-id comparison in `evaluateActivation`. (d, moving the block into main, is M and can follow.)
4. **H1** — `stopApi()` on `will-quit`, not `before-quit`.
5. **H4** — recents IPC refuses unauthorised paths; sanitise dialog defaults.
6. **H3** — respawn the backend once after an exit-after-ready; never adopt an external backend when packaged; stop children before `process.exit(1)`; reload once on renderer death. (S-M)
7. **H2** — three rotated `.strix` generations; `pg_dump` before any migration; named message for a newer database. (S / M)
8. **C4** — push develop and let CI run; `release` chains `dist`; git SHA in About; verify the reused Python tree by manifest. (S-M)
9. **H6 + H5** — `autoInstallOnAppQuit = false` until signing; launch-time activation refresh before the URL goes live.
10. **M1** — `pgdata` under `%LOCALAPPDATA%` before the first external install.

Post-beta, in this order: M3 timeouts · M4 strict schemas + `lazy="raise"` · M2 DOV cache/back-off · M7 scaling (canvas markers, virtualised lists, Cesium request-render, voxel progress/cancel, chunked DOV commits, chunked plot-batch) · M5 per-stage boundary · M6 sheet window hardening · M8 · the Lows.

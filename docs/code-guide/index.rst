StrixGeo Code Guide
===================

.. CG-EXPLANATION-START id=intro

This guide shows the StrixGeo source — the Python engine (backend) and the
Electron desktop app — one page per file, split into small blocks. Under every
block of real code is a plain-English explanation of what it does and why it is
there.

Start with :doc:`start-here`, then read the numbered groups in order: groups 1-7
are the backend engine, groups 8-13 the desktop app.

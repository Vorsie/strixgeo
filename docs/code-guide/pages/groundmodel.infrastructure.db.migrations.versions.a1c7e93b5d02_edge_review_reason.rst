.. CG-EXPLANATION-START id=module-header

**What this does.** Opens the migration that adds a ``review_reason`` column to the litho-contact correlation-edge table — a free-text note saying why a carried edge needs a second look, or empty when it does not. Names its revision id and the migration it follows.

**Why it is here.** The docstring records the geotech re-anchor sets it when a re-subdivide could not confidently identify the band an accepted tie was drawn on: the tie is carried onto the band covering most of its old position and flagged rather than dropped, per the owner's rule (2026-08-02) that an accepted edge never disappears without the engineer deleting it. It is free text (not an enum or check) so a new reason needs no migration, and hand-written, not autogenerated, for the reason recorded in migration 2244cb54aa1c.

# Support

## Questions

Ask questions in GitHub Discussions: https://github.com/Vorsie/strixgeo/discussions

Use Discussions for "how do I ...", for ideas you want to talk through first, and for anything that is not a bug.

## Bugs and feature requests

Open an issue with one of the templates: https://github.com/Vorsie/strixgeo/issues/new/choose

A good bug report contains:

- the StrixGeo version (Help > About StrixGeo);
- the Windows version;
- the data source (DOV, a GEF file, a borehole XML file, a PDF report, a lab export) and, if you can share it, the file;
- the steps that show the problem, what you expected and what you saw;
- the saved support logs (Help > Save logs for support).

## Security

Do not report a vulnerability in a public issue. See [SECURITY.md](SECURITY.md) for how to report it privately.
